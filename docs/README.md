# Dokumentacja projektu i przekazanie pracy

Stan dokumentacji: 17.11.2026. Jest to zapis wykonanych prac, decyzji użytkownika i rzeczywistych granic weryfikacji, przygotowany do dalszej pracy w Aion UI z Claude Code i Codexem.

## Kolejność czytania

1. [Przekazanie do Aion UI](PRZEKAZANIE-AION-UI.md) — aktualny stan, polecenia startowe, podział odpowiedzialności i kolejna kolejka prac.
2. [Decyzje i zakres](DECYZJE-I-ZAKRES.md) — obowiązujące zgody, odmowy i źródła danych; odróżnienie ich od wcześniejszego briefu.
3. [Architektura](ARCHITEKTURA.md) — modele, przepływ danych, kontrakty plików i algorytm dróg.
4. [Historia prac](HISTORIA-PRAC.md) — szczegółowa rekonstrukcja etapów i powodów zmian.
5. [Uruchomienie i testy](URUCHOMIENIE-I-TESTY.md) — powtarzalne uruchomienie, odbudowanie danych i diagnostyka.
6. [Bieżąca weryfikacja](../map05/VERIFICATION.md) — wykonane sprawdzenia, wyniki i ograniczenia dowodów.
